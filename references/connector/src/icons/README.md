References Add uses the existing BashKitten Office References open-book artwork,
with its SVG retained here as the source. The browser version uses black strokes
to match the other native toolbar controls. It is separate from the main
BashKitten application logo.

The transparent PNGs supply the native extension action and extension-manager
icons at 16, 32, 64 and 128 pixels. The Connector build copies these retained
assets into its existing `Icon-*.png` paths; it needs no new rendering dependency.
