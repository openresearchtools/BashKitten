# BashKitten browser integration

Product branding, browser features and build inputs for the shared Android/Linux
Firefox ESR tree. The Agent server and Pi integrations live in `/agent`; tracked
authentication sources live in `/auth`.

Use the repository's GitHub Actions workflows for builds. Firefox revisions and
product versions are recorded in `upstreams.toml` and `config/version.txt`;
[UPDATING-FIREFOX.md](UPDATING-FIREFOX.md) describes ESR updates. Retained licenses
and source attribution are described in [LICENSE-POLICY.md](LICENSE-POLICY.md).
