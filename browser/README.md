# BashKitten browser

The shared Firefox ESR source for BashKitten on Android and Linux. The browser
opens the Agent interface and controls ordinary browsing tabs; its server and
stock Pi run separately in Termux or Linux.

Builds and complete source are published from
[openresearchtools/bashkitten](https://github.com/openresearchtools/bashkitten).
See [Firefox updates](bashkitten/UPDATING-FIREFOX.md) and the
[integration plan](../docs/browser-integration-plan.md) for development.

Mozilla, Waterfox, WildBuzzard and retained third-party licenses remain with
their source. Full notices are available offline in About → Licenses.
