# Systematic Reviewer for BashKitten

A bundled stock Pi extension and research skill using the shared References
backend and native Collabora sessions. See [capabilities](docs/capabilities.md),
[References CLI](docs/references-cli.md), [citations](docs/citations.md) and
[setup](docs/setup.md). Scientific workflows remain researcher-selected.

The immutable donor import is in `vendor/v3`: committed pristine source, the
reviewed 17 tracked modifications and 31 untracked additions, materialized combined
source, binary delta and SHA-256 manifests. `vendor/main` pins the four search UI/
core reference files separately. Runtime code does not import either donor tree
or depend on the original sibling checkout. Full license and changes are in
[LICENSE](LICENSE) and [NOTICE](NOTICE).

Native facilities are reused: stock Pi registration/mutation queues; existing
worker/session authorization; shared References metadata/CSL/settings/resolver jobs;
and separate authenticated native Collabora views, save and export. The narrow
adapter gap is translation from retained research-tool/Markdown interfaces to
those shared project-qualified operations. The runtime has no desktop reference
application, replacement agent loop, custom credential system or DOCX serializer.
